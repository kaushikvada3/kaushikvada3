# Hi, I’m Kaushik.

I’m a physical design intern at **Tenstorrent**. Before that, I worked on SoC physical design at **Arm**. What drew me to chip design was seeing how a choice on paper plays out in silicon. Two gates can look like neighbors in a schematic, but the wire between them can be the reason a chip misses timing.

Lately, I’ve been exploring how machine learning can help engineers choose which operating conditions to test a chip under. The question that keeps me interested is simple: if we run fewer checks, can we still find the paths that fail?

Outside my internships, I’ve worked on **Project Obsidian**, a 2D graphics accelerator, and taken a **two-level cache** from RTL through clock-tree synthesis. I also developed *Hands-On Introduction to Industry Chip Design Tools* to give other people a way into the field.
